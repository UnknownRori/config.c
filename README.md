# config.c

is a simple custom .ini or .cfg reader and writer that I made for 
my very own need that simple to use and also with builtin memory leaker, 
but who cares leaking few bytes, it's not like I will use it multiple times.

example:

```ini
[app]
title="Rori"
fps=24
vsync=true
filter="nearest"
```

## Dependency

- malloc, memcpy, assert
- [rstb](https://github.com/UnknownRori/rstb/)
